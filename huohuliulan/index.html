常见问题 (FAQ)

下载速度慢怎么办？

请检查您的网络连接。如果下载速度极慢，建议更换下载镜像源或稍后再试。Firefox 官方服务器在全球多地都有节点。

安装后如何设置为默认浏览器？

安装完成后，Firefox 会自动询问是否设为默认浏览器。如果未询问，您可以在 Windows 的“应用默认值”设置中找到 Firefox 并将其设为默认。

Firefox 会收集用户数据吗？

Firefox 致力于隐私保护，默认关闭数据发送。您可以在设置中查看和调整您的隐私偏好。
